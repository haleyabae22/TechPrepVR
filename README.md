# TechPrepVR
Interactive 3D VR application for technical interview preparation, designed for Meta AI goggles using Mathematica prototypes.

## Project Status
This project is a prototype for an interactive VR 3D environment that helps users prepare for technical interviews.
Designed to work with Meta AI goggles, it demonstrates immersive simulations, problem-solving exercises, and interactive learning experiences.
Work is experimental and incomplete; the focus is on proof-of-concept VR interactions.
